# Processed Dataset Directory

This directory stores the partitioned, cleansed, and stratified datasets generated from the raw Flipkart review data.

## Excluded Artifacts

In compliance with repository hygiene and storage best practices, generated dataset CSV files are excluded from Git version control.

The following files are generated by the automated preprocessing script:
- `cleaned_reviews.csv`: Cleaned full dataset with normalized summary text and parsed numeric ratings.
- `sentiment_train.csv`: Stratified 80% training split (~73,512 records).
- `sentiment_validation.csv`: Stratified 10% validation split (~9,189 records).
- `sentiment_test.csv`: Stratified 10% independent test split (~9,189 records).
- `ambiguous_labels.csv`: Log of records with semantic contradictions between rating score and review summary polarity.
- `data_quality_report.json`: Statistical audit report documenting null imputation, class distributions, and token length quantiles.

## How to Generate Processed Splits

1. Obtain `Dataset-SA.csv` and place it into `data/raw/Dataset-SA.csv` (see `data/raw/README.md`).
2. Run the preprocessing script from the project root:
   ```bash
   python scripts/prepare_dataset.py
   ```
3. To initialize and seed the local SQLite database for the API and frontend:
   ```bash
   python scripts/initialize_database.py
   ```
